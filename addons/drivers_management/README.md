# Drivers Management Module

## Overview
The Drivers Management module is designed to facilitate the management of drivers within an organization. This module provides functionalities to create, update, and manage driver profiles, including their personal information, status, and platform IDs.

## Features
- Manage driver profiles with personal information and documentation.
- Track driver status (active, inactive, lead).
- Integration with various ride-sharing platforms.
- User-friendly views for managing drivers.

## Installation
1. **Clone the repository** to your local machine.
2. **Install the module** by placing it in the Odoo addons directory.
3. **Update the app list** in Odoo to include the new module.
4. **Install the Drivers Management module** from the Odoo apps interface.

## Usage
- Navigate to the Drivers Management application from the Odoo dashboard.
- Use the provided views to manage driver records, including creating new drivers and updating existing ones.
- Utilize the search and filter functionalities to easily find specific drivers based on their status or other criteria.
